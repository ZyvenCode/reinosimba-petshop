# Reino do Simba — demonstração de site

Abra `index.html` no navegador ou no VS Code com Live Server.

## O que já funciona
- Layout responsivo inspirado na demonstração criada.
- Produtos em destaque.
- Carrinho com quantidade e total.
- Finalização do pedido pelo WhatsApp.
- Formulário de agendamento.
- Botões de WhatsApp.
- Seção de serviços, contato e informações da loja.

## Antes de apresentar para a loja
No arquivo `script.js`, troque:
const WHATSAPP = "5599999999999";
pelo número oficial do Reino do Simba.

As imagens usadas são imagens públicas carregadas por URL. Para a versão final, substitua por fotos reais da loja/produtos e pelo logo oficial.
